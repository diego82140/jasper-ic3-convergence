# Jasper convergence

Resolve the kit root from `${CLAUDE_PLUGIN_ROOT}`; if not expanded, use the directory two levels above this skill. Read its [AGENTS.md](../../AGENTS.md) completely. Respect the user's project setup and proof scope; keep this installed kit read-only and put runs in the user's shared workspace.

Start from the RTL structure around the target; when it has a producer-window/owner shape (a pipeline, queue or counter carrying an identity into a state machine or flag array), a default first candidate family is their stage-wise relations ([inductiveness-method.md](../../references/inductiveness-method.md)). Admit a candidate only with a named consumer and a relevance witness; run a bounded witness search on its negation when the violating scenario is deep or environment-dependent. Then use telemetry to tell a depth ladder from a recurring induction family, derive a small helper when needed, prove it and its nonvacuity covers in family-sized bounded proves, measure its effect in a matched rerun, and validate the proved-only dependency graph in a plain-Jasper cold replay whose budget is derived from a bounded basis run of the same graph (no run is unlimited). No fixed design, signal vocabulary or helper template is prescribed. Attempt the learning procedures in AGENTS.md §5 when their verification conditions have a native checker; otherwise record the exact part as NOT_RUN rather than claiming execution. Diagnostics, capture/adapter qualification and actual target proofs have separate dispositions. Never weaken assumptions or turn incomplete telemetry into a certificate.

Read applicable sections of [telemetry-storage.md](../../references/telemetry-storage.md) when launching, querying, displaying or recovering captures. It covers Formal execution, disk/gzip collection, complete streaming selectors, trusted index receipts, sparse unknowns and release capability limits. Use AGENTS.md §§3–6 for diagnosis, learning and replay. [convergence-method.md](../../references/convergence-method.md) supplies primary theory references when needed; it does not repeat the instructions. The fuller AGENTS.md defines the learning procedures to attempt, the certificate gates and the honest capability limits. Maintainers use [telemetry-maintenance.md](../../references/telemetry-maintenance.md) and [validation.json](../../references/validation.json) for implementation lessons and exact test provenance; validation designs are not proof facts for a new design.
